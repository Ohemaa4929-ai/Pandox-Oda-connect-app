What's built (all 33 spec sections)

  • Auth & verification — customer/provider registration, Ghana Card/Passport/Driver's Licence workflow (PENDING → UNDER_REVIEW → APPROVED/REJECTED), encrypted ID storage (AES-256-GCM)
  • Modules — transportation/rides, delivery, hotels, Airbnb/short-stay, apartments/property with listings, rooms, vehicles, availability
  • Bookings — rides, delivery, hotel nights, property; cancel per policy; ratings & reviews
  • Payments — Paystack (Ghana), server-side verification + HMAC webhooks, never trusts frontend; NOT CONFIGURED until keys set
  • Financial ledger — pending/successful/failed/cancelled/refunded/disputed; corrections create adjustment records, history never silently changed
  • Subscriptions — customer + provider (3-month) plans, owner-configurable price/period/trial from dashboard
  • Commissions — per-category percent + fixed fee, owner-configurable
  • Owner Dashboard — 20 stat cards, users/providers/verifications/listings/bookings/disputes/transactions/refunds/subscriptions/commissions/reports, staff, audit log, sessions, settings, policies, campaigns, control center
  • Admin roles — SUPER_ADMIN, FINANCE, VERIFICATION, SUPPORT, DISPUTE, CONTENT, TECH; strict server-side RBAC
  • Super admin security — 2FA (TOTP), 12h sessions, rate limiting, login monitoring, session revocation, never hardcoded credentials
  • Audit log — every admin action recorded, no modification path
  • Control center — pause registrations/bookings/payments, disable modules, maintenance mode; all logged
  • Disputes — raise, notes, investigate, resolve, close
  • 13 legal policies — versioned, acceptance tracking, reviewable for Ghanaian requirements
  • Notifications — in-app always, email/SMS when configured, campaigns
  • Search & location — search, filters, categories, city; maps when configured
  • Reports — revenue/commission/provider earnings/bookings/users/providers/refunds/service performance by day/month/year
  • Security — helmet headers, rate limiting, input validation, parameterized SQL, XSS-safe output, secure uploads
